## 1. Executive Summary

This investigation explored the MITRE D3FEND framework and its
application to defensive cybersecurity operations.

MITRE D3FEND provides a knowledge base of defensive cybersecurity
techniques and their relationships to adversary behaviors.

The investigation focused on identifying defensive techniques,
understanding defensive tactics, exploring security detection
mappings, and examining file access and resource access concepts.

All five challenge questions were successfully completed.

## 3. Investigation Findings

### Finding 1: Defensive Technique Identification

**Scenario:**
Identify the corresponding name for MITRE D3FEND technique
D3-SDMP.

**Investigation:**

Researched the D3FEND technique catalog and examined how
defensive techniques are organized and identified.

**Security Significance:**

Standardized defensive technique identifiers help analysts
document security controls and communicate detection and
mitigation strategies.

---

### Finding 2: Five Defensive Tactics

**Scenario:**
Identify the five general tactics used to classify
defensive methods within MITRE D3FEND.

**Findings:**

The five defensive tactics are:

1. Harden
2. Detect
3. Isolate
4. Deceive
5. Evict

**Security Significance:**

These tactics describe different defensive objectives,
including reducing attack opportunities, identifying
malicious activity, containing threats, misleading
adversaries, and removing malicious access.

---

### Finding 3: Microsoft Sentinel and MITRE Framework Mapping

**Scenario:**
Research an open-source project that retrieves Microsoft
Sentinel detection rules mapped to MITRE ATT&CK and
generates related MITRE D3FEND defenses.

**Investigation:**

Explored how security detection rules can be connected
to adversary techniques and corresponding defensive
countermeasures.

**Security Significance:**

Mapping detection rules to MITRE frameworks can help
SOC analysts:

- Identify potential detection gaps.
- Understand which attacker behaviors are monitored.
- Evaluate defensive coverage.
- Prioritize security improvements.
- Communicate detection capabilities.

---

### Finding 4: File Access Pattern Analysis

**Scenario:**
Investigate the meaning of File Access Pattern Analysis
within the D3FEND framework.

**Investigation:**

Examined how patterns of file access may provide
indicators of suspicious or unauthorized activity.

Potential areas of investigation include:

- Unusual file access frequency.
- Unexpected access to sensitive files.
- Abnormal file access sequences.
- File activity inconsistent with normal user behavior.

**Security Significance:**

Monitoring file access patterns can support investigations
involving unauthorized access, insider threats, and
potential data theft.

---

### Finding 5: Local Resource Access

**Scenario:**
Investigate the Local Resource Access artifact within
MITRE D3FEND.

**Investigation:**

Examined the concept of accessing resources located
within a local computing environment.

Considered how local resource access relates to
permissions, authorization, and system security.

**Security Significance:**

Understanding resource access is important for:

- Access control monitoring.
- Identifying unauthorized activity.
- Investigating privilege misuse.
- Protecting sensitive system resources.
